Shenzhen file share

File Share Cheat Sheet

Alist is retired. This is a single small script now — a folder on the server is the app. No accounts, no admin panel, nothing to configure.

The link

<SERVER_IP>:8080/<folder>/ send a folder's or file's own link

The bare address <SERVER_IP>:8080/ shows visitors nothing — the top level is not listed. People can only open a folder or file whose exact link you gave them, so a folder's name is its key: use one that is hard to guess. Anyone holding a folder's link sees everything inside it, including its subfolders.

Passwords: each top-level folder has its own viewing password, set and shown on the management page (⚙ 设置 → 访问密码). A visitor is asked for it before anything in that folder opens, then stays signed in on that device for 30 days. A folder without a password is open to anyone who has its link — the management page marks it with a red 🔓 badge. Five wrong tries from one address lock that address out for 10 minutes, and that includes your own admin login. The site-wide shared password was switched off on 2026-10-10; to bring it back, add a VIEW_PASS=… line to ~/fileshare/docker-compose.yml and run docker compose up -d there.

What a visitor sees

  • Clicking a file's name opens it in the browser. That address is the file's direct link.
  • 🔗 复制链接 on each row copies that direct link — paste it to someone and they open the file (or folder) in one click, without browsing the listing.
  • ▦ 二维码 on each row shows a QR code for that item's direct link — scan it with a phone camera to open it, or press 保存图片 to save the code and send it. The code is just the link drawn as a picture: no redirect service, and the folder's password is still asked for.
  • ⬇ 下载 on each file row saves the file instead of opening it.
  • Images show a thumbnail beside the name. Clicking one opens a full-screen viewer: flip through the folder's images with the ‹ › buttons, the arrow keys, or a left/right swipe on a phone; ✕, Esc or a tap on the dark area closes it. The same viewer works on the management page.
  • A folder with an expiry shows its date at the bottom of the page.
  • The page fits a phone (the two buttons shrink to their icons and the date column is hidden) and widens to 1120px on a large screen.

Add or remove a file

Add a file — appears on the link instantly, no restart: 
scp yourfile.pdf sz:~/fileshare/shared/
Remove a file: 
ssh sz 'rm ~/fileshare/shared/yourfile.pdf'

The management page

Management page — type or bookmark this address (password-protected — browser will prompt once and remember it): 
<SERVER_IP>:8080/upload
Username / password 
saved on your Mac: SZ_FILESHARE_USER / SZ_FILESHARE_PASS
in the gitignored .env at the root of the Gokapi-FileShare repo
On the server they are set as UPLOAD_USER / UPLOAD_PASS in ~/fileshare/docker-compose.yml.
  • Layout: upload and new-folder sit at the top; below them is the list of what is in the current folder. The path under the title (根目录 / folder) is clickable, and clicking a folder's name opens its own management page.
  • Upload: drag files onto the dashed area, or click it to pick them, then press 上传. A bar shows the percentage. A file whose name already exists is kept alongside it as name (1).ext, never replaced.
  • Each row has four buttons: 🔗 复制链接 copies the item's direct link, ▦ 二维码 shows its QR code, ⚙ 设置 opens its settings underneath, and 删除 removes it after a confirmation.
  • ⚙ 设置 → 改名: rename a file or folder. A name that is already taken is refused.
  • ⚙ 设置 → 访问密码 (top-level folders only): gives that folder its own viewing password; the current one is shown in the box. Leave it empty to remove the password, which leaves the folder open to anyone with its link. A folder with its own password shows a 🔒 独立密码 badge; one without shows a red 🔓 badge.
  • ⚙ 设置 → 几天后自动删除 (top-level folders only): enter a number of days from now. When they are up the folder and everything in it is deleted automatically, with no undo; a red badge on the row shows the date and days left. Empty or 0 cancels it.
  • After any change you stay on this page and a line at the top says what happened.
  • Visitors never see a link to this page. Once you have logged in here, your own browser shows a "🛠 管理文件" link on every folder listing until it forgets the login.

Good to know

  • Runs as Docker container fileshare, restarts automatically unless you stop it — survives crashes and reboots.
  • Files live at ~/fileshare/shared on the server — that directory listing is the whole site.
  • PDFs and images open directly in the browser's own viewer — no external service involved, so nothing to be slow or blocked from China.
  • The old HTTPS link (port 9443) is gone along with Alist — this app is HTTP only, which was the friendlier link for friends anyway.
Source: ~/fileshare/server.py on the server — one file, standard library only, nothing to install.
