Shenzhen file share

File Share Cheat Sheet

Alist is retired. This is a single small script now — a folder on the server is the app. No accounts, no admin panel, nothing to configure.

The link

<SERVER_IP>:8080/ unchanged — nothing to resend

Add or remove a file

Add a file — appears on the link instantly, no restart: 
scp yourfile.pdf sz:~/fileshare/shared/
Remove a file: 
ssh sz 'rm ~/fileshare/shared/yourfile.pdf'

Upload from a browser

Upload page (password-protected — browser will prompt once and remember it): 
<SERVER_IP>:8080/upload
Username / password 
set via UPLOAD_USER / UPLOAD_PASS in fileshare/.env

Lets you upload, rename, delete, and copy a share link for anything — files and folders — without SSH. Every folder listing has a "🛠 管理文件（上传 / 改名 / 删除）" link in the corner that opens this page pre-scoped to that folder.

Good to know

  • Runs as Docker container fileshare, restarts automatically unless you stop it — survives crashes and reboots.
  • Files live at ~/fileshare/shared on the server — that directory listing is the whole site.
  • PDFs and images open directly in the browser's own viewer — no external service involved, so nothing to be slow or blocked from China.
  • The old HTTPS link (port 9443) is gone along with Alist — this app is HTTP only, which was the friendlier link for friends anyway.

Quick share — private one-off links

A second, separate app — a local clone of the quickshare tool on Cloudflare. No browsable listing: each upload gets its own private link, and that link is the only way to find the file.

Upload page: 
<SERVER_IP>:9000/
Upload key (pasted into the page, not a browser prompt): 
set via UPLOAD_TOKEN in quickshare-sz/.env

Select one or more files at once — each gets its own independent link (e.g. /f/<id>/name.ext), so sharing several files still means sharing several separate links.

Source: ~/fileshare/server.py on the server — one file, standard library only, nothing to install.
